My Eco System

О проекте
Модульное приложение для управления личной информацией и учебным процессом. Проект находится в стадии активной разработки (MVP).
Включает в себя модули для ведения клинического дневника, изучения языков, подготовки к экзаменам, философских заметок и многого другого.

Стек технологий:
   Язык: Python
   GUI: Tkinter
   База данных: Firebase
   AI/LLM: Интеграция с API
   Библиотеки: matplotlib, requests, TTS

Реализованный функционал:
  Модульная архитектура (базовый класс + отдельные модули),
  CRUD операции (добавление, редактирование, удаление),
  Поиск и фильтрация записей,
  Сбор и визуализация статистики,
  TTS-движок (озвучка текста).

В планах (Roadmap):
  Восстановление вызовов LLM в новом UI (интерфейс в процессе рефакторинга),
  Внедрение Embeddings для семантического поиска,
  Переход на современный UI (Flet / CustomTkinter).
