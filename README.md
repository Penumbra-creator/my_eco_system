My Eco System («Цифровой гиппокамп»)

О проекте
Персональная система управления знаниями, объединяющая учебные, клинические и личные домены в единую экосистему с интеграцией AI. Проект находится на стадии активной разработки (готовность ~70-80%).

Стек технологий
   Язык: Python
   GUI: CustomTkinter (миграция с классического Tkinter)
   База данных: Firebase (Realtime Database, офлайн-режим, авторизация)
   AI/LLM: Мультипровайдерный слой (Gemini, Groq, Ollama). Локальные модели для приватных данных, облачные — для качества.
   Парсинг: Scrapy, Playwright (очереди, ретраи)
   Инфраструктура: Docker, Redis, Git
   Дополнительно: TTS-движок, собственный SRS-движок (интервальное повторение)

Реализованный функционал
  11 доменов: Клиника, Статьи, Сны, Философия, Язык, Экзамены, Билеты, Стратегия, Конфликт, Книга жизни, Моторика.
  AI-слой: Переключение между провайдерами, уникальные промпты для каждого домена.
  SRS-движок: Связывает учебные домены для эффективного повторения.
  Синхронизация: Firebase для realtime-обновлений и работы офлайн.
  Парсинг: Автоматическое извлечение выжимок из статей по ссылке.
  TTS: Озвучка карточек для прослушивания в дороге.
  Оптимизация: Ленивая загрузка модулей (устранение задержек при старте).
  CRUD: Полный цикл работы с записями, фильтрация, поиск, сортировка.

Текущий статус и планы (Roadmap)

  Внедрение векторного поиска (Embeddings + RAG).
  Разработка API-слоя для веб и мобильной версии.
  Полное покрытие тестами (Pytest).

Как запустить
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Создать файл `.env` или `config_data.py` на основе шаблона и добавить API-ключи.
4. Запустить `main.py`.
